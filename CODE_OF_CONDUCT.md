# Code of Conduct

This project follows the Contributor Covenant (v2.1). In short:

- Be respectful and inclusive.
- No harassment, discrimination, or abusive language.
- Respect privacy and personal boundaries.

If you witness or are subject to unacceptable behavior, contact the maintainers at: conduct@forge-ai.local. All reports will be handled sensitively and promptly.

See CONTRIBUTING.md for more information on how to engage with the project.
